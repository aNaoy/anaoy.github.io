### Modernisation des systèmes hérités par l'IA : Avancées de GPT-6.1 Sol

OpenAI a annoncé une amélioration significative des capacités de son modèle GPT-6.1 Sol pour l'écriture et la migration de langages de programmation « hérités » (Legacy), tels que COBOL, Fortran et Visual Basic, qui soutiennent des infrastructures critiques (banques, systèmes de sécurité nucléaire, prévisions météorologiques).

**Points clés :**
*   **Performance accrue :** Le nouveau modèle atteint un taux de réussite de 87,4 % sur le benchmark *MultiLangBench* (contre 26,8 % pour la version précédente).
*   **Migration de code :** GPT-6.1 Sol démontre une précision de 97,9 % lors de la conversion de code COBOL vers des langages modernes (C++, Java, Kotlin, Python, Rust) avec un coût opérationnel réduit.
*   **Évaluation des compétences :** OpenAI utilise *MultiLangBench*, un test standardisé consistant à créer un moteur de base de données SQLite à partir de zéro dans 20 langages différents.

**Recommandations :**
*   **Validation humaine :** Bien que les capacités de migration soient en nette progression, toute conversion de code dans un environnement de production doit impérativement faire l'objet d'une revue technique par des experts et de tests de validation rigoureux.

*Note : L'article ne mentionne aucune vulnérabilité spécifique ni CVE associée à cette technologie.*
