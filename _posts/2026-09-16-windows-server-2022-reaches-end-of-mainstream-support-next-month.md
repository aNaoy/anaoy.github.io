### Fin du support standard pour Windows Server 2022

Windows Server 2022 atteindra la fin de son support standard le 13 octobre 2026. À cette date, le système entrera dans une phase de support étendu qui se poursuivra jusqu'au 14 octobre 2031.

**Points clés :**
*   **Transition de support :** Après le 13 octobre 2026, seuls les correctifs de sécurité mensuels seront fournis sans coût supplémentaire.
*   **Hotpatching :** Pour les systèmes *Datacenter: Azure Edition*, la fonctionnalité de hotpatching est prolongée jusqu'en octobre 2027.
*   **Successeur désigné :** Windows Server 2025 est la nouvelle version LTSC (Long-Term Servicing Channel) disponible, avec un support standard actif jusqu'en novembre 2029.

**Vulnérabilités :**
*   Aucune CVE spécifique n'est mentionnée dans cet article ; il s'agit d'une annonce liée au cycle de vie des produits Microsoft.

**Recommandations :**
*   **Planification des mises à jour :** Les administrateurs système sont invités à anticiper la migration vers Windows Server 2025 pour bénéficier d'un support complet.
*   **Tests de déploiement :** Il est conseillé d'évaluer les options de mise à niveau et de commencer les tests de déploiement dès maintenant.
*   **Essai gratuit :** Une version d'évaluation de 180 jours de Windows Server 2025 est disponible via le Centre d'évaluation Microsoft pour faciliter les tests.
