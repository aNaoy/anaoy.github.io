### Fin du support standard pour Windows Server 2022

Windows Server 2022 atteindra la fin de son support standard le 13 octobre 2026. À cette date, le système basculera en phase de support étendu jusqu'au 14 octobre 2031, date à laquelle toutes les mises à jour cesseront.

**Points clés :**
*   **Transition de support :** La mise à jour de sécurité d'octobre 2026 sera la dernière du cycle de support standard.
*   **Support étendu :** Les mises à jour de sécurité continueront d'être fournies sans coût supplémentaire jusqu'en 2031.
*   **Hotpatching :** Pour les systèmes *Datacenter: Azure Edition*, la fonctionnalité de hotpatching est prolongée jusqu'en octobre 2027.
*   **Nouvelle version :** Windows Server 2025 est désormais disponible en tant que dernière version LTSC (Long-Term Servicing Channel).

**Vulnérabilités :**
*   Aucune CVE spécifique n'est mentionnée dans l'article ; il s'agit d'une annonce de cycle de vie logiciel.

**Recommandations :**
*   **Planification des mises à jour :** Les administrateurs système sont invités à anticiper la migration vers **Windows Server 2025** afin de bénéficier d'un support standard complet.
*   **Tests de déploiement :** Il est conseillé de commencer les phases de test dès maintenant pour garantir une transition fluide.
*   **Évaluation :** Microsoft propose une version d'essai gratuite de 180 jours de Windows Server 2025 via son centre d'évaluation pour faciliter les tests en environnement de pré-production.
