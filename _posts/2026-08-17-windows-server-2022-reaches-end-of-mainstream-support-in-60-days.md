### Transition de Windows Server 2022 vers le support étendu

Microsoft a rappelé aux administrateurs IT que le support principal de Windows Server 2022 prendra fin le 13 octobre 2026. À cette date, le système d'exploitation basculera en phase de support étendu jusqu'au 14 octobre 2031, date à laquelle les mises à jour de sécurité cesseront définitivement.

**Points clés :**
*   **Fin du support principal :** La dernière mise à jour de sécurité du support principal sera publiée en octobre 2026.
*   **Support étendu :** Les mises à jour de sécurité mensuelles continueront d'être fournies sans coût supplémentaire pendant la phase étendue (jusqu'en 2031).
*   **Hotpatching :** Pour les systèmes *Datacenter: Azure Edition*, le support du « hotpatching » a été prolongé jusqu'en octobre 2027.
*   **Nouvelle norme :** Windows Server 2025 est désormais la version LTSC (Long-Term Servicing Channel) la plus récente, offrant un support complet jusqu'en 2029 (extensible jusqu'en 2034).

**Vulnérabilités :**
*   Aucune vulnérabilité spécifique (CVE) n'est mentionnée dans cet article ; il s'agit d'une communication relative au cycle de vie des produits.

**Recommandations :**
*   **Planification des mises à niveau :** Il est conseillé de migrer vers Windows Server 2025 pour bénéficier d'un support principal complet et garantir la sécurité à long terme des environnements.
*   **Tests :** Microsoft encourage le déploiement précoce de tests via la version d'évaluation gratuite de 180 jours de Windows Server 2025 afin d'assurer une transition fluide.
