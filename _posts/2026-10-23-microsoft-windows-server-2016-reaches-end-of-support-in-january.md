### Fin du support étendu pour Windows Server 2016

Microsoft a confirmé l'arrêt définitif du support de Windows Server 2016 pour le 12 janvier 2027. Après cette date, aucune mise à jour de sécurité, correctif ou support technique ne sera fourni pour les éditions Datacenter, Essentials, MultiPoint Premium et Standard.

**Points clés :**
*   **Échéance :** La dernière mise à jour de sécurité sera déployée en janvier 2027.
*   **Portée :** L'arrêt concerne toutes les fonctionnalités du système, incluant les services spécifiques à l'édition Essentials comme le "Remote Web Access".
*   **Risques :** L'utilisation d'un système d'exploitation non supporté expose les infrastructures aux menaces cybernétiques en l'absence de correctifs pour les nouvelles vulnérabilités découvertes.

**Vulnérabilités :**
*   Aucune CVE spécifique n'est mentionnée dans l'article, mais l'absence de futurs correctifs rendra le système vulnérable par nature à toute faille critique découverte après janvier 2027.

**Recommandations :**
*   **Planification de migration :** Les administrateurs systèmes doivent migrer vers **Windows Server 2025**, la version LTSC (Long-Term Servicing Channel) la plus récente, supportée jusqu'en 2034.
*   **Phase de test :** Microsoft met à disposition une version d'évaluation gratuite de 180 jours via le *Microsoft Evaluation Center* pour faciliter les tests de compatibilité avant le déploiement en production.
