### Mise à jour de Microsoft PowerToys : Introduction de "Window Hopper"

Microsoft a déployé la version 0.101.2362.0 de PowerToys, introduisant plusieurs améliorations fonctionnelles destinées à optimiser la productivité sous Windows.

**Points clés**
*   **Window Hopper :** Ajout d'un utilitaire permettant de basculer rapidement entre les fenêtres d'une même application active via un raccourci clavier (Alt + accent grave par défaut).
*   **Améliorations de l'interface :** Intégration d'un mode compact pour le lanceur "Command Palette".
*   **Gestion des périphériques :** Support du contrôle de la luminosité synchronisé pour plusieurs écrans (PowerDisplay).
*   **Nouveaux outils de démonstration :** Introduction de "DemoMirror" (pour la duplication d'écran sur moniteur secondaire) et d'un mode "Ripple" pour le surlignage de la souris.

**Vulnérabilités**
*   Aucune vulnérabilité n'est mentionnée dans cette mise à jour.

**Recommandations**
*   **Mise à jour :** Les utilisateurs souhaitant bénéficier de ces fonctionnalités doivent mettre à jour leur version de PowerToys vers la version 0.101.2362.0 via le [dépôt GitHub officiel](http://github.com/microsoft/PowerToys/releases/).
*   **Configuration :** Il est recommandé de personnaliser les raccourcis clavier dans les paramètres de PowerToys pour adapter "Window Hopper" aux habitudes de navigation spécifiques.
