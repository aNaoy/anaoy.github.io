### Fin du support standard pour Windows Server 2022

Windows Server 2022 est entré dans la phase de support étendu depuis le 13 octobre 2026, marquant la fin de son support standard (Mainstream Support). Bien que ce changement n'affecte pas la disponibilité des mises à jour de sécurité, il souligne la nécessité de planifier une migration vers des versions plus récentes.

**Points clés :**
* **Statut de support :** Le support standard a pris fin le 13 octobre 2026. Le support étendu se poursuivra jusqu'au 14 octobre 2031, incluant les mises à jour de sécurité mensuelles gratuites.
* **Hotpatching :** Pour les systèmes *Datacenter: Azure Edition*, le service de hotpatching est prolongé jusqu'en octobre 2027.
* **Nouvelle version :** Microsoft recommande la migration vers Windows Server 2025, disponible depuis novembre 2024, pour bénéficier du support standard complet jusqu'en novembre 2029.

**Vulnérabilités :**
* Aucune vulnérabilité spécifique (CVE) n'est mentionnée dans cet article ; le sujet porte exclusivement sur le cycle de vie du produit et la gestion du support logiciel.

**Recommandations :**
* **Planifier la migration :** Les administrateurs IT doivent initier la transition vers Windows Server 2025 afin de maintenir un environnement pleinement supporté et sécurisé.
* **Tester la compatibilité :** Il est conseillé d'utiliser la version d'évaluation gratuite de 180 jours de Windows Server 2025 disponible via le Microsoft Evaluation Center pour valider les déploiements avant migration.
* **Vigilance logicielle :** Microsoft rappelle également l'importance de maintenir à jour tous les systèmes d'exploitation (y compris Windows 11) pour éviter toute perte de protection suite à l'arrêt des mises à jour de sécurité sur les versions obsolètes.
