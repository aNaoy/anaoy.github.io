### Fausse alerte de désactivation de Microsoft Defender

Microsoft a officiellement confirmé l'existence d'un bug provoquant l'affichage de notifications erronées indiquant que « Microsoft Defender Antivirus est désactivé », alors que la protection reste parfaitement opérationnelle sur les systèmes concernés.

**Points clés :**
* **Nature du problème :** Des alertes trompeuses apparaissent au démarrage de Windows et de manière intermittente, même si les paramètres système confirment que l'antivirus est actif.
* **Périmètre :** Le bug touche toutes les versions supportées de Windows (clients et serveurs), incluant Windows 11 26H1 et Windows Server 2025.
* **Historique :** Le problème a été identifié initialement dans le canal Windows Insider dès juin, mais n'a été reconnu par Microsoft qu'à la suite de rapports d'utilisateurs généralisés après les dernières mises à jour.
* **Vulnérabilités :** Aucune faille de sécurité n'est associée à ce problème ; il s'agit d'un dysfonctionnement lié à l'interface de notification (faux positif).

**Recommandations :**
* **Action immédiate :** Microsoft conseille aux utilisateurs d'ignorer ces alertes si le statut de l'antivirus dans l'application « Sécurité Windows » confirme que la protection est active.
* **Correction à venir :** Aucune intervention manuelle n'est nécessaire pour le moment ; un correctif sera déployé prochainement via une future mise à jour automatique de Microsoft Defender Antivirus.
